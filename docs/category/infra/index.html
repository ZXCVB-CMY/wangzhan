奥迪创新技术中心上海开业，上汽奥迪四款新车2028年首发

11月5日，奥迪创新技术中心正式在上海开业。该中心由奥迪股份公司与上汽集团共同组建，是专门服务AUDI品牌的研发实体，具备整车开发与端到端研发能力，将夯实奥迪在中国市场的本土化研发体系。

点评奥迪与上汽共建研发中心，本土化研发提速以应对中国市场竞争。
