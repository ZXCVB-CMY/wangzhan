新能源矩阵扩充，NISMO正式引入 NISSAN DAY开启品牌进阶

11月13日，由日产（中国）、东风日产、郑州日产共同打造的NISSAN DAY在珠海国际会展中心启幕。日产汽车首席执行官伊凡·埃斯皮诺萨视频致辞，表达深耕中国、以中国创新助力全球市场的信心。

点评品牌焕新叠加新能源产品扩容，日产在华转型节奏明显加快。
